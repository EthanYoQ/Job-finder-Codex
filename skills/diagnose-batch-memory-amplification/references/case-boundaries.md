# 已验证案例的边界

以下为去标识、非秘密的方法案例，不含生产材料，也不提供复跑授权。

一次抓取处理中，155 行反复解析同一约 2.13 MB HTML。原运行在 256 MiB V8 堆限制下出现堆耗尽并 SIGABRT。修复把重复解析改为同输入作用域复用，不提高堆、超时或降低质量门。

记录的离线 admission 耗时从 72.8 秒降至 9.4 秒；heapUsed 观测值从 213.4 MiB 降至 161 MiB。这些数字只适用于该次测量，不能当作通用收益或未声明口径的峰值。离线没有重现原 OOM，所以不能称“离线复现后修复”。

后续真实运行完成 155 条采集，并分别完成入库与网页验收。此结果支持该次真实运行通过，不证明所有规模、输入或未来批次均无 OOM。RSS/PSS 只做进程树采样，没有验证整机峰值或整机安全余量。

本例说明应检查放大因子，而不是说明所有 OOM 都来自 HTML/DOM。Buffer、副本、并发队列、原生扩展和无界保留仍需按证据排查。
