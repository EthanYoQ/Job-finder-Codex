# 测量与验收

## 最小测量记录

- 对象：代码哈希、运行时版本、输入字节和行数、运行 ID、输入指纹（不用原文或秘密）、真实/合成输入、解析选项、并发与资源限制。
- 时间：开始、结束、采样间隔、采样窗口。区分进程内测点、定时采样最大值、系统高水位和终点值。
- 内存：V8 heapUsed/heapTotal；原生/Buffer 相关 external/arrayBuffers；RSS；必要时 Linux PSS、cgroup memory.current/memory.peak 与 OOM 事件。只有实际测到才报告。
- 进程树：以 PID 和启动时间识别进程，记录动态发现与采样遗漏。汇总 RSS 会重复计算共享页。PSS 按比例分摊共享页，但进程树 PSS 也不是整机用量。
- 工作量：解析调用数、处理/接受/拒绝行数、批次与重试次数、队列或并发峰值。缩小工作量后的内存下降不构成等价修复证据。

采样最大值是下界，可能漏掉短峰。结束后的 heapUsed 较低不能证明峰值较低。强制 GC 可帮助研究保留，但必须两侧采用同样方法并披露，不能与正常运行混算。若基线已经失败，不能将失败前的低终点值与修复完整运行比较为峰值改善。

## 验收矩阵

| 层 | 可证明 | 不能替代 |
| --- | --- | --- |
| 合成单元测试 | 受测模式的身份隔离、调用次数、结果/拒绝等价 | 真实解析器、原始 OOM、生产工作量 |
| 同输入离线回放 | 该输入与条件下的结果、性能及观察到的内存 | 未重现的故障、网络采集、写入状态 |
| 受限堆真实采集 | 指定运行在原限制下完成真实采集 | 数据库已提交、网页已更新、长期无泄漏 |
| 持久化回读 | 指定批次/调用的实际存储结果 | 用户网页显示 |
| 同批网页验收 | 网页暴露的对应数据与状态 | 整机容量保证、历史错误被修复 |

重复批次验证应覆盖稳态，不只一个批次。实际 OOM 未重现时仍可提交确定的重复分配修复，但故障归因保留推断强度。离线回放不得发出真实写入；若无法保证隔离，停止并说明阻断。
