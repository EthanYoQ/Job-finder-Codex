# 诊断批处理内存放大

目标是在既定架构、执行环境、资源限制和结果质量内减少不必要分配，并用分层证据证明修复范围。用户已明确这些约束时，任何偏离都先说明原因、影响和替代方案并取得同意。技能本身不授权生产重跑、外部写入或部署。

## 定位前固定边界

1. 记录失败运行的代码版本、输入身份、行数、字节数、运行时、启动参数、堆限额、并发数、退出码/信号和原始错误。保留失败记录。不要用新成功覆盖旧失败。
2. 区分 V8 堆耗尽、内核/容器 OOM kill、超时及其他 SIGABRT 原因。SIGABRT 单独不足以证明 OOM。读取已有 stderr、容器限制与可用的内核事件；缺证据就标未知。
3. 明确这次允许执行哪一层：合成测试、真实输入只读回放、真实采集、入库、网页验收。只在获准层执行。若此前写入结果不明，先回读原调用和目标状态，不能因超时、缺日志或离线成功盲目重放。

## 找到放大因子

先测量再选修复。每项测量写明对象、采样方式、时间窗口和单位。heapUsed、heapTotal、external、arrayBuffers、单进程 RSS、进程树 RSS/PSS、容器用量与整机余量不是同一口径；arrayBuffers 通常已包含在 external 中，不能相加。详见[测量与验收](references/measurement-and-acceptance.md)。

- 检查循环内是否反复解析同一 HTML/JSON、重复构建索引、展开或深拷贝整个输入、反复序列化，或把同一大字符串装进每条记录。记录调用次数与输入大小，而非只看耗时。
- 检查未受限的 Promise.all、队列积压、闭包/事件监听器、跨批缓存和错误对象对原始输入的保留。稳定平台可能是工作集；跨批持续增长更像保留问题。用数据判断，不默认是 DOM。
- 原始字节很小也可能展开为大量对象。区分累计分配、瞬时峰值和批结束后的保留；堆快照会暂停进程、占磁盘并可能包含敏感输入，仅在获准环境使用。

## 做最小且语义等价的修复

确认存在同输入重复纯解析时，可在一次输入/批次作用域内解析一次并复用只读结果。不要直接复制参考实现到生产。先确认生产解析器的可变状态和异常行为。

- 缓存身份至少覆盖完整输入内容和所有影响解析的选项。URL、公司名、行号或长度不够。同 URL 的新内容不得复用旧结果。最好让缓存随单次输入上下文创建与销毁，避免全局 Map。
- 必须跨输入缓存时，明确容量/字节上限、淘汰策略和并发隔离。散列键须覆盖完整内容与选项，并考虑碰撞核对；不可为做缓存又保留无界原文副本。
- 若下游会修改 DOM/解析对象，先去掉修改或隔离可变部分。不能为省解析偷偷改变后续记录。批次结束、拒绝、异常和取消路径都应释放强引用；释放引用不等于 GC 已回收，也不保证 RSS 立即降低。
- 保持输出内容、顺序、去重键、错误/拒绝条件、质量门、超时和资源限额。延迟解析不得引入新拒绝行为；提前解析不得把原本无需解析的记录变成失败。改变并发时核对顺序、限流和重试语义。
- 使用共享子树或压缩序列化减少重复分配时，另查字节合同：对象语义相等不保证字段顺序、共享判定或重新编译的声明字节相等。原字节摘要应在文本解码前计算；不能用排序键或解码后的字符串摘要替代原件身份。项目中的限定案例见[来源与证据编译问题](../../docs/job-finder/source-evidence-repair-notes.md#1-servier共享-json-的语义可逆不等于字节可逆)；该案例不构成 OOM 归因或内存收益证明。
- 不用提高堆、加长超时、降低质量门、少抓记录或换架构冒充修复。确有容量需求时独立说明证据，提出替代方案并按用户约束请求批准。

## 分层验收和交付

1. 先跑合成等价测试：相同输入多行、同长度不同内容、选项变化、并发上下文隔离、拒绝与异常路径、批结束释放。比较完整结果和错误语义，并检查实际解析次数。可执行本技能的 `node --max-old-space-size=256 scripts/test-scoped-parse-reuse.mjs`；该测试只验证模式，不证明生产 OOM。
2. 用相同输入、启动参数和测量口径对比基线与修复。记录耗时和内存，不用单次结束值冒充峰值。旧版本未在离线重现 OOM 时写“离线未重现”，即使修复更快也不能声称已复现并消除原故障。
3. 在已有授权下做原受限堆的真实工作负载验证。真实采集成功、入库回读通过和网页同批验收分别给结论。无生产授权时停在离线结论，交付下一步验证条件。
4. 交付最小补丁、合成测试、命令、代码/输入身份、指标口径、旧失败与新结果对应关系、剩余缺口。明确哪些是观察、推断和未知。需要恢复操作时，先查明原外部写入是否已执行，再决定是否允许新调用。

已有案例只作方法参考，见[已验证案例的边界](references/case-boundaries.md)。合成测试不联网、不写数据库、不读取生产文件；不自动发布或备份。
