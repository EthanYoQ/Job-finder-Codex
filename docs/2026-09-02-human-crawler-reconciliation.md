# 2026-09-02 人工基线与抓取结果核对

## 结论

人工表被保存为有日期的外部校准快照，不是抓取器的输入。生产抓取代码禁止导入该快照，测试会扫描 `src/` 并在发生依赖时失败。因此程序不能读取人工数量后把结果凑到相同数字。

一次结果只有同时满足以下条件，才可判为当前可置信结果：

1. 来源身份正确：入口来自企业官网或官网明确认可的招聘渠道。
2. 范围请求正确：中国地域、社会招聘、业务边界等筛选实际进入 HTTP 请求，而不只出现在页面文字中。
3. 遍历闭合：官方总数或末页信号与抓到的全部页面一致。
4. 转换可核对：原始行数、解析数、有效数、去重数和每一条丢弃原因全部记账。
5. 职位级核对：以职位 ID/官方 URL 集合判断新增、下架、重复和越界；数量只作告警信号。

## 独立审查后的发布边界

GPT-5.6 Sol Pro 的对抗审查指出：换一个 Agent 重放同一适配器并不构成独立验证，因为它仍可能继承错误的范围假设。数量相同、请求可重放和分页闭合也只能证明“稳定取得了某批数据”，不能单独证明那批数据就是用户需要的中国社招范围。

因此把两个状态分开记录：

- 当前数据状态：可发布、不完整或隔离。
- 历史比较状态：相等、差异未归因、时间变化候选、口径冲突或基线未知。

独立抽查前最多有 33 家候选发布源：20 家匹配、11 家时间变化候选、CSL 和华润医药。它们仍需满足本节开头的当前证据规则；数量匹配不自动放行。诺华、赛诺菲、礼来、武田、石药、联邦制药、翰森和强生共 8 家先隔离，不进入当前职位、完整数量汇总或通知，也不记为零。

首轮独立抽查固定为 8 家，不再人工逐家检查：

1. 定向检查 BMS、CSL、科伦，以及 Aspen／大冢／基立福／齐鲁中随机固定一家。
2. 从其余候选源按共用适配器和分页实现分层随机抽 4 家，其中至少 2 家来自数量匹配组；冻结抽样种子和名单，不因结果不理想而换样本。
3. 每个样本只独立确认官方入口和生效范围、取得官方职位 ID／URL 集合、检查集合差和最多 3 条详情。发现单公司错误就隔离该公司；发现共用实现错误就隔离全部受影响来源并复核同路径另一家。
