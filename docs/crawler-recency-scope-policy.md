# 招聘职位半年窗口规则

## 规则

未来可抓取企业的社会招聘职位默认只保留观测时点前 183 个中国自然日内发布或变更的职位。该规则适用于新增扩展候选，也适用于以后重新校准的已有企业；它不追溯改变已冻结的 41 家首发批次定义。

如果官方来源提供原生时间筛选器，必须优先复用官网同一参数和口径；只有没有原生筛选器时，才使用可靠发布日期或变更日期在抓取器内过滤，并在抓取损失台账中记录被时间窗口排除的数量。Moka 使用 `publishedAt`，静态招聘页使用页面公开发布日期。

如果官方来源提供原生“180 天”过滤器，可将 180 天视为官方半年窗口，但必须保存实际参数和值，不能在报告中写成 183 天。北森 2022 官网的“半年内”使用请求体 `PostDate:[180]`；艾力斯旧版北森页面使用 `d=180`。不得用 `ChangeDate >= 183 天截止日` 替代这些原生筛选，因为职位变更日期不等于官网用于“发布时间”的范围语义。

如果官方列表既没有可靠日期，也没有官方时间过滤器，必须标记 `TIME_WINDOW_UNAVAILABLE`。不得推测发布日期，也不得把该企业称为“半年窗口已完整验证”。

## 校对口径

每轮校对同时记录官方原始数、范围/时间排除数、去重数和最终数。人工数量是历史基线，不是程序需要强行命中的目标；任何非零差值，包括绝对值不超过 2 的差值，都必须复盘职位集合、时间点和唯一标识方法。

职位唯一标识优先使用官方职位 ID；没有逐职位唯一 ID 时使用规范化后的官方详情 URL。不得使用多个职位共享的栏目 ID、内容类型 ID或 DOM 容器 ID。
