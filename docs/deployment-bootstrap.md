# Deployment bootstrap and readiness

Set `DATABASE_URL`, `ADMIN_EMAIL`, and a unique `ADMIN_PASSWORD_HASH` generated by
`hashAdminPassword`. Placeholder, malformed, missing, or disabled administrator configuration
fails closed without printing credential material.

Run the non-interactive command once on a new server:

```text
npm run ops:bootstrap
```

The command runs the repository-local `prisma migrate deploy` before an advisory-lock-serialized administrator
creation transaction. Repeating or concurrently invoking it is safe when the configured administrator is unchanged. First creation emits
an `AdminAuditEvent`; a conflicting or disabled administrator returns a nonzero exit code.

In Compose, the one-shot `bootstrap` service runs after PostgreSQL is healthy and `web` starts only
after bootstrap succeeds. `/livez` reports process liveness only. `/readyz` (with `/healthz` kept as
the internal compatibility alias) returns Ready only when the database is reachable, every local
Prisma migration is applied, and the configured administrator is enabled with the configured hash.
Do not route public traffic to an instance returning 503 from `/readyz`.
