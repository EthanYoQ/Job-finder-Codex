# Triage Labels

| Canonical role    | Local status      | Meaning                                    |
| ----------------- | ----------------- | ------------------------------------------ |
| `needs-triage`    | `needs-triage`    | Maintainer must evaluate the issue         |
| `needs-info`      | `needs-info`      | More evidence or reproduction is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready to implement     |
| `ready-for-human` | `ready-for-human` | Requires human intervention                |
| `wontfix`         | `wontfix`         | Will not be actioned                       |

When a skill refers to a triage role, use the corresponding local status verbatim.
