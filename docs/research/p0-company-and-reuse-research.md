# P0 公司候选池与可复用模块调研

更新时间：2026-07-07

## 结论摘要

Grill-me 已结束。P0 范围定为：外资药企中国区、国内 Top 30 药企、国内知名 Biotech、可从官方主页追溯到标准 ATS 的药企。P0 不做医美、区域型中小药企、器械公司前台覆盖；器械和医美产品型公司放后续阶段。

P0 公司库不是单纯公司名清单，而是“公司 + 招聘入口状态”表。所有招聘入口必须从公司官方主页或官方招聘页追溯；允许跟随官方链路进入 Moka、北森/Zhiye、Workday、SuccessFactors、Redsea 等第三方 ATS。

P0 完成标准已确认：候选池覆盖约 80-120 家公司，其中至少 50 家达到“已验证可抓取”。

## 公司库字段

建议后台公司表至少包含：

| 字段 | 说明 |
|---|---|
| 公司中文名 | 前台唯一展示名，使用中国官网/中国业务官方中文名 |
| 英文名 | 后台字段，前台不展示 |
| 入选依据 | 外资药企中国区、国内 Top 30、知名 Biotech、用户指定、标准 ATS 可追溯等 |
| 依据来源 | 公开榜单、用户指定、官网核验等 |
| 官网 URL | 必须从官方主页开始核验 |
| 官网核验状态 | 未核验 / 已核验 / 无法访问 / 需人工确认 |
| 社招入口 URL | P0 前台只展示社会招聘岗位 |
| 校招入口 URL | P0 只记录入口，不进入搜索结果 |
| 官方链路证明 | 例如“官网 > 职业发展 > 职位机会 > 社会招聘 > ATS” |
| 招聘系统类型 | 自建、Moka、北森/Zhiye、Workday、SuccessFactors、Redsea、51job 专题页等 |
| 抓取状态 | 未核验 / 已找到入口待适配 / 已验证可抓取 / 暂不可抓取 / 暂不纳入 |
| 最近核验时间 | 后台字段 |
| 备注 | 入口异常、移动端入口、需公众号跳转等 |

## 后续核验路径

1. 从候选池中按优先级逐家公司打开官方主页。
2. 记录官网导航链路：官网 > 职业发展/人才招聘 > 社会招聘/校园招聘 > ATS。
3. 每家公司先判定社招入口，校招只记录。
4. 对社招入口做三层测试：Jina/HTTP 直读、浏览器 DOM、网络请求/API。
5. 满足“连续两次可返回岗位结构化字段”的公司，才标记为已验证可抓取。
6. 达成至少 50 家“已验证可抓取”后，才满足 P0 数据源完成标准。
