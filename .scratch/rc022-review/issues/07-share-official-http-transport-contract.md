## Agent Brief

**Summary:** Centralize repeated official HTTP request and timeout wrappers used by source fetchers.

**Current behavior:**
Several source fetchers repeat the same request, response, client, and default-timeout shapes. Safety or metadata changes can diverge across copies.

**Desired behavior:**
A shared internal transport contract supplies the common request/response and timeout wrapper while each source retains its provider-specific behavior.

**Acceptance criteria:**
- [ ] Common transport shapes have one definition
- [ ] Existing source-level interfaces and evidence remain unchanged
- [ ] Timeout and safe-response tests cover the shared contract
- [ ] Provider-specific parsing remains outside the shared transport module

**Out of scope:**
- Combining provider parsers
- Changing retry counts or timeout policy
