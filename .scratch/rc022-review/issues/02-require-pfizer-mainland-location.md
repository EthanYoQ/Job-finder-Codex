# 02 — Require explicit mainland location for Pfizer completeness

**Category:** bug
**Status:** ready-for-agent
**Priority:** P1

## Agent Brief

**Summary:** Prevent APAC-only Pfizer jobs from proving China-source completeness or entering normalized output.

**Current behavior:**
The strict Pfizer Workday policy accepts the exact descriptor `APAC - Any Pfizer Site` when no public location explicitly names mainland China. An India-primary job can therefore pass completeness, become a normalized Pfizer China job, and contribute to release qualification.

**Desired behavior:**
The Pfizer China source may publish and count only records whose audited public detail contains at least one explicit mainland China location. Broad or exact APAC descriptors can remain supporting location text only when a mainland location is also present; they cannot substitute for it.

**Key interfaces:**
- Strict Workday detail replay — require an explicit mainland descriptor
- Normalized job output — never emit APAC-only location values for the Pfizer China source
- Source completeness result — fail closed when the only eligible-looking descriptor is regional

**Acceptance criteria:**
- [ ] India plus exact APAC-only detail fails completeness and emits no jobs
- [ ] India plus an explicit Shanghai/China additional location still succeeds
- [ ] Broad or altered APAC descriptors continue to fail closed
- [ ] The regression is verified through the source crawl public seam

**Out of scope:**
- Replacing Pfizer's official source
- Changing generic Workday behavior for unrelated companies
- Treating APAC as equivalent to China
