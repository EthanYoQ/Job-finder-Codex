Non-secret project/source identifiers, original absolute paths, hashes and synthetic test identities are retained in the originals.

Producer 28402a299bb04cbf5873da66c2fe8ca76827c0d1, the pinned Node runtime, installed dependencies and genuine separately authorized bindings are still required. The archive does not recreate original execution state or a registered runtime identity.

The tests are source artifacts, not an archive-isolated executable package. They require the original host locations; source-key tests can execute the actual external loader and local compiler/inspector. Their tool shim is not a general operating-system sandbox. Keep Python assertion checks enabled. Regenerating fragments at another path changes their embedded source location and pins and needs its own validation.

Coverage must be described precisely: the unchanged original suite has 22 synthetic cases; each of the two generated suites adapts those 22 cases. Only one reviewed-entry case per generated suite traverses preload, entry and owner, for two such cases total. The other generated cases call the owner directly. Additional source-key/preload tests cover separate loader and invalid-input scenarios. Source-author test results are not tests performed by this backup process or a claim of complete CI/production acceptance.

Backup checks used static text, exact hashes, literal generator reconstruction, unchanged baseline comparison and immutable dependency mapping. No source, generator, tests, SQL, capture or deployment was executed for this backup. PROCESS_TERMINATED remains separate from publication reconciliation.
