The upstream Apache-2.0 LICENSE and NOTICE are retained beside the guidance. SOURCE_BACKUP.json records the original paths, exact Git blobs, and SHA-256 values. Verify SHA256SUMS when restoring the directory.

This snapshot contains documentation only. It does not include credentials, profiles, environment files, diagnostic responses, executable tools, or dependencies. Restoring it does not install or run the CLI, register an integration, or change any account settings. Examples remain unmodified upstream reference text and require separate evaluation before use.
