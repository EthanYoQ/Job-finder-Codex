# Four portable host source snapshots

Frozen source, synthetic tests and necessary nonsecret configuration/templates for BMS, Astellas, Grifols and Biogen. Each contributes 41 files after excluding LAUNCH_HOLD. The preparation cutoffs and exact input hashes are recorded in RESTORE_INPUTS.json; historical null-candidate/template labels do not describe current operational state.

Repository paths preserve the layout relative to the recovered project root. The three shared legacy test references are reused from [Organon 5d3918c](https://github.com/EthanYoQ/Job-finder-Codex/tree/5d3918ca49b094f6aefbb14e70ec6691f363dd7d). Their old absolute wrapper paths remain, so file availability does not establish full historical-suite runnability.

Dependencies: Node.js >=22, the producer's locked packages including tsx/zod/cheerio, Python 3, Bash, Linux /proc and POSIX process/filesystem facilities, and the original host tool mapping. Astellas PDF support additionally requires the producer's resource-limited PDF tools; no binary installation or PDF capability is established by this backup. Application changes are already archived in [3687335](https://github.com/EthanYoQ/Job-finder-Codex/tree/368733577fe5a3d395393c6464fc23eb3fa99c80). The complete original Git graph, installed packages and runtime are not included.

The original rebuild_unactivated_hosts.py is preserved without edits. It supports only Astellas, Grifols and Biogen, uses fixed absolute paths and hashes, rejects existing destinations, and leaves partial output on failure. It runs local checks and generated scripts if executed; it is not a passive file-copy tool. Review its inherited environment and dependencies before use, including NODE_OPTIONS/NODE_PATH. This backup did not execute it.

The recipe requires the original pinned BMS manifest and all 42 baseline entries, including the omitted LAUNCH_HOLD file, two separately archived static/official reference JSON files, the Merck dependency manifest and the fixed producer/runtime. Their hashes are recorded, but their contents are not all present here. The recipe cannot be run solely from this filtered GitHub snapshot; missing inputs must be restored and revalidated, not fabricated or bypassed.

Actual activation/control, fresh binding responses, SQL write packets, run folders, raw records, credentials and execution reports are excluded. Recompute restored source/runtime identities and require exact fresh registration bindings. Fixed SQL candidate IDs must agree with those bindings. Template status LOCAL_UNREGISTERED is not an activation status, and a new namespace does not clear existing UNKNOWN outcomes or the formal lock. The unused ARCHIVE_STORE branch still needs its omitted audit/transfer helpers.

Only the original recipe code is retained from the four common delivery items; the original long README and two result reports are excluded with hashes. No source execution, tests, database operations, CI, merge or deployment were performed for this backup. SOURCE_BACKUP.json and SHA256SUMS identify exact archived bytes.
