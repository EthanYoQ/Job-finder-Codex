# Grifols host source compatibility snapshot

This preserves 21 frozen host source/configuration files and four supplemental synthetic test/generator/fixture files for the incremental receipt contract. The context query unwraps legacyCertificate inside a delta receipt. The publication envelope parser uses the producer's shared atomic JSON compiler and receipt validation. It is a source snapshot, not an end-to-end publication or restoration result.

Restore the relative hosts/grifols/host and hosts/grifols/supervision layout under the corresponding runtime root. The files retain fixed absolute roots, source/project/candidate selectors and expected build/database hashes. The producer dependency is dfd22f642469888eb781f5e7b93964a60e082ca0, whose safe application source increment and baseline requirements are in [a47ed7f](https://github.com/EthanYoQ/Job-finder-Codex/tree/a47ed7feeb93e99d45633795cb5fecebc8c0818f). No full Git history, dependencies or registered runtime are included here.

Operational recovery requires genuine Node 22.19.0/tsx/Prisma dependencies, the matching producer/shared compiler, compatible Python/Linux process support, and the authorized orchestration tools. Several JavaScript files are orchestration fragments using tools/load/store, not standalone Node entry points. Actual activation.json and control-base.json are deliberately absent and cannot be reconstructed by treating source constants as a current registration receipt. Recover and verify the required runtime/registration bindings through the approved procedure before use; changing a candidate selector also requires regenerating and rechecking its exact context query and pins.

prepare-registered-control.mts is preparation source only. It requires the separately recovered control/build template and a fresh registration readback, writes a new preparation directory, and does not supply the missing activation state. The dormant ARCHIVE_STORE path also refers to an external legacy archive audit/Library helper not provided by this snapshot.

The non-secret host-config.json is included exactly as frozen. Actual run directories, relay requests/responses, captures, diagnostics, registration material, SQL results, proxy/environment values and credentials are excluded. The four supplemental files preserve their runtime-root-relative layout. Their list/detail responses are fixed mocks and the packet SQL is synthetic, with an empty database job context and a synthetic-only candidate/batch. The packet has an absolute expiry: it is a frozen example, not a timeless test input. Re-running positive tests requires the separately verified build-identity input and synthetic-evidence files generated in an isolated test environment; these dependencies are not in this snapshot. Do not edit frozen timestamps or treat synthetic activation objects as real registration. No source, test, query, capture, CI, deployment or registration action was executed by the backup.
