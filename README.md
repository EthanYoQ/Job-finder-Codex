## Boundaries

Actual activation, control, context, bound loader/starter/owner files, registration inputs and readbacks, run artifacts, logs, database rows, captured content and credentials are excluded. The included exit-42 tool-result fixture contains real metadata from a purely synthetic child-process test, not a production run; its exact bytes are required by the regression test. Static pins and project-specific paths are intentionally retained.

Historical checks described in SAFE_SOURCE_README.md are the source provider's records. This backup verified file paths, modes and exact content without executing the sources or tests. It makes no CI, deployment, live collection or publication claim. Use SOURCE_BACKUP.json and SHA256SUMS for this backup's precise contents and exclusions.
