## Owner test path boundary

The preserved continuous-owner suite constructs synthetic private-file overlays from its current extraction location, while retained loader/preload code still uses the original absolute host paths. At a different extraction location, unmatched reads can fall through to the actual original filesystem. Therefore do not describe that suite as location-independent or private-read-proof: use the exact declared recovery layout, or separately fix and verify its overlay/fallback handling before testing from another location. The dedicated restore-only harness is a distinct path; selected owner test results do not establish this broader isolation claim. No such reads or tests were performed by this backup.
